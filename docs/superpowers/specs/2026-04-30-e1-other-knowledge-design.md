## 三、各节内容设计

### 16.1 信息系统（了解）

**核心内容**：5 类信息系统对比表

| 系统 | 全称 | 用户层级 | 核心功能 | 典型决策类型 |
|------|------|---------|---------|------------|
| **EDPS** | 电子数据处理系统 | 操作层 | 替代手工事务处理 | 结构化（程序化） |
| **MIS** | 管理信息系统 | 中层管理 | 内部数据汇总报表 | 结构化（程序化） |
| **DSS** | 决策支持系统 | 中高层 | 半结构化决策辅助 | 半结构化 |
| **OAS** | 办公自动化系统 | 各层 | 办公文档/工作流 | — |
| **ES** | 专家系统 | 专业领域 | 模拟专家推理 | 非结构化 |

**关键 callout**：
- `> [!important]` 5 类信息系统对比表
- `> [!tip]` 速记：EDPS 替手工、MIS 出报表、DSS 辅决策、OAS 办公、ES 模专家

### 16.2 未来信息综合技术（了解）

**核心内容**：6 项主流技术名词级介绍

- **人工智能 AI**：弱 AI / 强 AI；机器学习（监督/无监督/强化）；深度学习；典型应用（NLP / CV / 推荐）
- **区块链**：去中心化、不可篡改、分布式账本；公有链 / 联盟链 / 私有链；典型共识 PoW / PoS
- **物联网 IoT**：感知层 / 网络层 / 应用层 三层架构；常用协议 MQTT / CoAP / LoRa
- **云计算**：3 服务模式 IaaS / PaaS / SaaS；4 部署模式公有 / 私有 / 混合 / 社区
- **大数据**：5V 特征 Volume / Velocity / Variety / Veracity / Value；Lambda / Kappa 架构
- **VR / AR / MR**：虚拟现实 / 增强现实 / 混合现实区分

**关键 callout**：
- `> [!important]` 云计算 3 服务模式 IaaS/PaaS/SaaS 边界
- `> [!important]` 大数据 5V 特征
- `> [!tip]` IoT 三层架构记忆：感知层是设备、网络层传输、应用层处理
- `> [!warning]` VR / AR / MR 区分：VR 全虚拟、AR 现实+虚拟叠加、MR 现实虚拟交互

### 16.3 应用数学（了解）

**核心内容**：

- **图论基础**：
    - 有向图 / 无向图 / 加权图
    - 最短路径：**Dijkstra 算法**（贪心、单源）
    - 最小生成树：**Prim 算法**（贪心、加边）/ **Kruskal 算法**（贪心、按权重排序）
- **运筹学**：
    - **线性规划**：标准型、目标函数、约束条件
    - **动态规划**：最优子结构 + 重叠子问题（如背包问题、最长公共子序列）
- **决策树**：期望货币值 EMV（参见 [[13-项目管理#EMV期望货币值]]）
- **概率论基础**：条件概率、贝叶斯公式
- **排队论**：M/M/1 模型基本概念

**关键 callout**：
- `> [!important]` Dijkstra（最短路径）vs Prim/Kruskal（最小生成树）速辨
- `> [!tip]` 动态规划判定：最优子结构 + 重叠子问题
- `> [!note]` 决策树详见 [[13-项目管理]] EMV 计算

### 16.4 专业英语（了解）

**核心内容**：考试高频术语对照表（30+ 词条）

按主题分组：
- **架构相关**：Architecture / Pattern / Component / Connector / Constraint / Decomposition / Cohesion / Coupling
- **质量属性**：Reliability / Availability / Maintainability / Scalability / Security / Performance / Usability
- **设计模式**：Singleton / Factory / Observer / Adapter / Decorator / Strategy
- **过程与方法**：Iteration / Increment / Sprint / Backlog / Retrospective / Refactoring
- **测试**：Unit Test / Integration / Regression / Coverage / Test Case
- **网络与安全**：Encryption / Authentication / Authorization / Firewall / VPN / Vulnerability
- **数据库**：Normalization / ACID / CAP / Transaction / Index

**关键 callout**：
- `> [!tip]` 应试策略：阅读理解题不要逐字翻译，抓主题词与对照专业术语即可
- `> [!note]` 词汇本身不会单独考查，常出现在阅读理解 5-7 题中
