## 三、各节内容设计

### 1.1 核心概念

#### 1.1.1 系统规划生命周期

| 阶段 | 主要任务 |
|------|---------|
| **战略规划** | 业务战略 → 信息化战略对齐 |
| **可行性研究** | 评估是否值得投资 |
| **立项决策** | 高层批准、预算批复 |
| **需求分析** | 用户需求获取与建模 |
| **设计实施** | 系统设计、开发、测试 |
| **运行维护** | 上线、运维、评价 |

#### 1.1.2 立项与可行性流程

**立项 4 步**：
1. **项目建议书**：提出项目设想、初步分析
2. **可行性研究**：详细评估（经济/技术/操作/法律）
3. **项目论证**：评审、修订、批准
4. **任务下达**：分解任务、组建团队

#### 1.1.3 可行性研究 4 大维度（必背）

> [!important] 可行性研究 4 维度

| 维度 | 关注点 | 典型问题 |
|------|--------|---------|
| **经济可行性** | 投入产出比 | NPV / IRR / 投资回收期 |
| **技术可行性** | 现有技术能否实现 | 团队能力、技术成熟度、风险 |
| **操作可行性** | 用户能否使用 | 用户接受度、培训成本、法律法规 |
| **法律可行性** | 是否合法合规 | 合同合规、知识产权、监管要求 |

**关键 callout**：
- `> [!important]` 可行性 4 维度（必背）
- `> [!tip]` 立项 4 步流程

### 1.2 关键技术与架构

#### 1.2.1 成本效益分析（经济可行性核心）

> [!important] 3 大经济指标公式

| 指标 | 公式 | 判定 |
|------|------|------|
| **NPV**（净现值） | NPV = Σ（CFt / (1+r)^t）- C₀ | NPV > 0 → 项目可行 |
| **IRR**（内部收益率） | 使 NPV = 0 的折现率 | IRR > 基准收益率 → 可行 |
| **投资回收期** | 累计现金流 = 0 时的时间点 | 越短越好（一般 ≤ 5 年） |

> [!tip] 速记
> - **NPV** = 把未来每年现金流折算到现在 - 投资额
> - **IRR** = 让 NPV = 0 的特殊折现率（项目自带的"利率"）
> - **投资回收期** = 几年内能"回本"

**计算示例**：项目投资 1000 万，未来 3 年现金流 400 / 500 / 600 万，折现率 10%。
- 第 1 年：400 / 1.1 ≈ 363.6
- 第 2 年：500 / 1.21 ≈ 413.2
- 第 3 年：600 / 1.331 ≈ 450.8
- NPV = 363.6 + 413.2 + 450.8 - 1000 ≈ ==227.6 万==（> 0，可行）

#### 1.2.2 系统规划方法

| 方法 | 全称 | 核心思想 |
|------|------|---------|
| **BSP** | Business Systems Planning（企业系统规划法） | ==自上而下==：识别业务过程、定义数据类、建 U/C 矩阵 |
| **CSF** | Critical Success Factors（关键成功因素法） | 找出对企业成功最关键的少数因素 |
| **SST** | Strategy Set Transformation（战略集合转化法） | 将组织战略转化为信息系统战略 |
| **VCA** | Value Chain Analysis（价值链分析法） | 从价值链角度分析信息需求 |

> [!tip] 4 种方法记忆
> - **BSP**：从业务过程出发（最经典、最常考）
> - **CSF**：抓关键因素
> - **SST**：战略转化
> - **VCA**：价值链视角

| 技术风险 | 评分 | 评分 | 评分 |

| 维护成本 | 评分 | 评分 | 评分 |

新旧系统比较：

- 切换风险（直接 / 并行 / 分段 / 试点，参见 [[../01-综合知识/11-系统运行与维护]]）

### 1.3 典型考点与解题套路

#### 1.3.1 可行性分析答题模板

> 第一段（理论）：可行性研究从 ==4 个维度==（经济、技术、操作、法律）评估项目是否值得投资。
>
> 第二段（分点分析）：
> - （1）**经济可行性**：投资 X 万、年收益 Y 万、NPV/IRR 计算 → 是否盈利
> - （2）**技术可行性**：团队 / 平台 / 关键技术 → 是否能实现
> - （3）**操作可行性**：用户接受度 / 培训 / 流程变更 → 是否能用起来
> - （4）**法律可行性**：合规 / 知识产权 / 监管 → 是否合法
>
> 第三段（结合场景）：综合 4 维度评估，本项目 ==可行 / 风险点在 X==。

#### 1.3.2 关键字判定速查

| 题目关键字 | 推荐 |
|----------|------|
| 投资是否盈利 / 现金流 | **经济可行性 + NPV/IRR** |
| 团队能力 / 技术成熟度 | **技术可行性** |
| 用户接受度 / 流程变更 | **操作可行性** |
| 合规 / 数据保护 / 监管 | **法律可行性** |
| 业务过程驱动信息化 | **BSP** |
| 找关键因素 | **CSF** |
| 战略对齐 | **SST** |

#### 1.3.3 NPV / IRR 计算套路

**NPV 计算 4 步**：
1. 列每年现金流 CFt
2. 选定折现率 r
3. 各年现金流折现：CFt / (1+r)^t
4. 累加 - 初始投资

**判断准则**：
- NPV > 0 → 可行
- NPV = 0 → 边界（IRR = 折现率）
- NPV < 0 → 不可行

**IRR 含义**：让 NPV = 0 的折现率。比"当前可用资金的成本（资本成本）"高 → 项目划算。

### 1.4 真题与练习

#### 1.4.1 真题示例 1：可行性 4 维度分析（高频）

**题目**：某连锁餐饮企业计划实施一套全国性的会员管理系统，覆盖 500+ 门店、500 万会员。请从可行性研究的 4 个维度分析该项目是否可行。

> [!example]+ 参考答题
>
> **理论**：可行性研究从 ==经济、技术、操作、法律== 4 个维度评估项目是否值得投资。
>
> **分点分析**：
>
> （1）**经济可行性**：
>   - 投资估算：硬件 + 软件 + 开发 + 5 年运维 ≈ 数千万
>   - 年收益：会员复购率提升、营销精准度提升 → 增收 / 节支
>   - 计算 NPV / IRR / 投资回收期
>   - 判断：NPV > 0 → 经济上可行
>
> （2）**技术可行性**：
>   - 关键技术：分布式架构（500+ 门店并发）、大数据分析（500 万会员画像）
>   - 团队能力：是否有云原生 / 大数据团队
>   - 平台选择：自建 vs 云服务（阿里云、腾讯云）
>   - 风险：跨地域网络延迟、门店离线场景
>
> （3）**操作可行性**：
>   - 用户接受度：500+ 门店店长 / 服务员能否使用
>   - 培训成本：分批培训、分层指导
>   - 流程变更：会员注册 / 积分 / 营销流程统一化
>
> （4）**法律可行性**：
>   - ==个人信息保护法==：500 万会员数据合规
>   - 等保 2.0 三级（金融/支付涉及）
>   - 数据出境（如有跨境业务）
>
> **结论**：从 4 个维度看，项目 ==经济与技术可行==、操作需充分培训、法律需重点合规。==建议立项，分阶段实施==（试点 → 推广）。

#### 1.4.2 真题示例 2：NPV/IRR 计算（中频）

**题目**：某项目投资 1000 万，未来 3 年现金流分别为 400 / 500 / 600 万。折现率 10%。请计算 NPV，并判断是否可行。

> [!example]+ 参考答题
>
> **理论**：NPV（净现值）= ==未来现金流折现总和 - 初始投资==。NPV > 0 → 项目可行。
>
> **分步计算**：
>
> 折现率 r = 10%，初始投资 C₀ = 1000 万
>
> **各年折现现金流**：
> - 第 1 年：400 / (1.1)^1 = 400 / 1.1 ≈ ==363.6 万==
> - 第 2 年：500 / (1.1)^2 = 500 / 1.21 ≈ ==413.2 万==
> - 第 3 年：600 / (1.1)^3 = 600 / 1.331 ≈ ==450.8 万==
>
> **NPV 计算**：
> - NPV = 363.6 + 413.2 + 450.8 - 1000 = ==227.6 万==
>
> **判断**：
> - NPV = 227.6 > 0 → ==项目可行==
> - 同时 IRR > 10%（折现率），项目自身收益率高于资本成本
>
> **结论**：项目 ==经济上可行==，3 年内不仅回本还能盈利约 227.6 万（折现后）。
