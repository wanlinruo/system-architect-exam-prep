## 3.2 关键技术与架构（待细化）

> [!note]+ 待补充内容
> - **MVC**：Model 业务、View 展示、Controller 接收请求并协调
> - **MVP**：View 通过 Presenter 与 Model 交互（View 被动）
> - **MVVM**：View 与 ViewModel 双向绑定，常见于 Vue / Angular
> - 三者对比表：数据流方向 / UI 测试性 / 学习曲线 / 典型框架
> - 物联网 3 层：感知层（传感器 / RFID）/ 网络层（5G/Wi-Fi）/ 应用层（业务平台）
